# Triple Espresso

## Descripción del proyecto

Triple Espresso es una página web para una cafetería ficticia ubicada en Triple Peaks.

El sitio presenta información sobre la cafetería y permite a los usuarios consultar sus horarios, encontrar su ubicación y completar un formulario para reservar una mesa. También incluye enlaces a las redes sociales de la cafetería.

El proyecto fue desarrollado utilizando HTML y CSS. Durante su desarrollo se utilizaron técnicas como Flexbox para la distribución de elementos, la metodología BEM para organizar las clases CSS y formularios HTML para la sección de reservaciones.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Metodología BEM

## Planes de mejora

En el futuro me gustaría agregar validación y procesamiento del formulario mediante JavaScript, de manera que las reservaciones puedan ser verificadas y almacenadas. También sería interesante implementar un diseño responsivo para adaptar correctamente el sitio a teléfonos y tabletas.
